# Lettering de umbra

La palabra en minúsculas está compuesta con Young Serif Regular y espaciado ajustado. Se exportaron los cinco glifos a contornos SVG para que el logo no dependa de una descarga de fuente. No son letras dibujadas originalmente para Umbra.

Fuente original: https://github.com/google/fonts/tree/main/ofl/youngserif

Archivo: YoungSerif-Regular.ttf. Licencia SIL Open Font License 1.1, incluida en YOUNG-SERIF-LICENSE.txt. El isotipo de apertura es independiente del lettering.
