# Workflow: Release

1. Review diff and scope.
2. Confirm input classification, decision sync, and evidence requirements.
3. Run checks.
4. Run production readiness when public/prod-facing.
5. Confirm support, rollback, restore, vendor fallback, monitoring, and accepted risks when relevant.
6. Update docs/changelog/PR notes after verification.
7. Ask approval for push/deploy/merge.
8. Monitor canary or production health.
9. Capture follow-up tasks and delivery health impact.
