# Workflow: Project Bootstrap

Use immediately after importing Agent OS into a new project, or when a repo has no trusted agent operating structure yet.

1. Read `.agent-os/PROJECT_BOOTSTRAP_PLAN.md`.
2. Run `.agent-os/workflows/guided-intake.md` when the project idea/profile is blank, stale, copied, or strategically incomplete.
3. Fill `.agent-os/PROJECT_PROFILE.md` from current code, docs, config, founder context, and the Project Alignment Packet.
4. Classify docs as hypotheses until verified against code/screens/runtime.
5. Choose or verify stack, deploy, database, auth, payments, AI/models, queues/workers, observability, tests, docs, and release gates.
6. Establish the UX research/flow baseline with `.agent-os/UX_RESEARCH_AND_FLOW_CONTRACT.md`: user needs, use cases, launch-critical flow traces, journey/service-blueprint gaps, IA/content terminology, UX metrics, event taxonomy, research loop, and support/recovery loop.
7. Establish the product-language baseline with `.agent-os/PRODUCT_LANGUAGE_CONTRACT.md`: category, value proposition, user vocabulary, navigation labels, core objects/actions, AI trust language, brand/metaphor boundaries, terms to use/avoid, and docs/code/UI/E2E terminology sync.
8. Establish the business/GTM baseline with `.agent-os/BUSINESS_GTM_CONTRACT.md`: ICP, anti-ICP, wedge, activation, retention, pricing/packaging, channels, support model, cost/margin posture, public claims, business metrics, and founder approvals.
9. Establish the founder communication baseline with `.agent-os/FOUNDER_COMMUNICATION_CONTRACT.md`: founder data package, founder brand vs product brand, story boundaries, content pillars, channel roles, public proof/claims, audience/ICP mismatch, reference-founder research, and feedback-to-product loop.
10. Register MCPs/tools/skills; quarantine anything unknown or broad-permission.
11. Register model/agent runtimes with `.agent-os/MODEL_AND_REVIEW_ORCHESTRATION.md`.
12. Run `.agent-os/SYSTEM_INTEGRITY_CONTRACT.md` to map source-of-truth, triggers, evidence, enforcement level, artifact lifecycle, risk register, automation backlog, and portability boundaries.
13. Convert prior CEO reviews, deep investigations, research chats, founder-story reviews, pricing/GTM plans, and market research into artifacts, decisions, evals, or explicit ignored inputs.
14. Define data/privacy/legal/vendor/IP scope.
15. Define scale/resilience/cost baseline with `.agent-os/SCALE_AND_RESILIENCE_CONTRACT.md`.
16. Update `AGENTS.md` and model-specific instruction files to point to the project profile.
17. Run agent evals for bootstrap, skills, tools, research, readiness, model/runtime behavior, system integrity, product language, business/GTM, founder communication, and portability.
18. Produce `artifacts/audits/<date>-project-bootstrap.md`.

Do not start feature work until the bootstrap output says the project is ready or records the accepted risks.
