# Project Research

Use research as evidence, not decoration. Run it when the outside world can change the decision.

Read `.agent-os/PROJECT_PROFILE.md` first so the research is grounded in the current project.

## Process

1. Define the decision and 3-5 subquestions.
2. Search current web sources and official docs.
3. Check the codebase for existing patterns.
4. Prefer official/provider docs, standards, primary sources, and current sources.
5. Identify contradictions and stale information.
6. State what changes in the plan and what does not.
