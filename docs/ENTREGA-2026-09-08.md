## Qué usar para la entrega

La [publicación `entrega-cae-2026-09-08`](https://github.com/mativelezx/umbra/releases/tag/entrega-cae-2026-09-08) es el punto de entrada definitivo: código con el parche de acceso, PDF/DOCX de 94 páginas sin cambios y evidencia visual posterior al parche. No se necesita un ZIP para acceder a la demo ni leer el repositorio. Las etiquetas anteriores se conservan como antecedentes, sin reemplazar sus archivos.

El usuario eligió mantener el enlace directo de Vercel. Esto fija la dirección de la web, no configura un remitente de correo. Para grabar o mostrar el recorrido disponible, usar la cuenta ficticia ya confirmada y sus resultados guardados. No presentar esa cuenta como prueba de recepción de correo de registro.

La última comprobación de cierre repitió las 409 pruebas web y verificó la integridad de los archivos publicados. No se cambió código de la aplicación, base de datos ni modelos después del despliegue `2b20073`; las actualizaciones siguientes son documentación y evidencia. Antes de abrir a usuarios externos siguen pendientes correo, restauración probada y control global de gasto. Son límites operativos separados del formato académico y del alcance experimental del ML, no condiciones que se den por aceptadas o resueltas.

## Cómo repetir el cruce del documento

Descargar PDF y DOCX de la publicación de esta reentrega. Instalar `python-docx` y `pypdf` en un entorno Python propio y ejecutar desde la raíz:

```bash
python scripts/verify-thesis.py /ruta/TFG_Umbra_Velez_SOF01994.docx /ruta/TFG_Umbra_Velez_SOF01994.pdf \
  --repo . \
  --manifest docs/evidence/reentrega-2026-09-08/document-manifest.json \
  --pages docs/evidence/reentrega-2026-09-08/pages.json \
  --output /ruta/resultado-cruce.json
```

Para repetir capturas de lectura, preparar una cuenta ficticia con resultados guardados y proporcionar `E2E_SYNTHETIC_PASSWORD` por variable privada. Revisar `e2e/release-evidence.spec.ts`; exige opt-in y restringe el destino. No publicar esa variable ni ejecutar pruebas pagas sin autorización.
